# 営業用ポートフォリオサイト

動画編集（YouTube・ショート動画）を紹介する営業用サイトです。
ページの最後に「AIを活用した業務効率化」のご案内と、AI活用の紹介サイトへ移動するボタンがあります。
HTML・CSS・JavaScriptだけで作っているので、インストール作業やビルド（変換作業）は不要です。

---

## 1. フォルダー構成

```
portfolio-site/
├── index.html            … ページ本体（文章・SEO・OGP設定）
├── config.js             … ★本番用データ（氏名・写真・メール・動画URL）ここだけ編集すればOK
├── config.example.js     … 記入例（サイトでは読み込まれません）
├── css/
│   └── style.css         … デザイン（色は先頭の :root で一括変更可）
├── js/
│   ├── vendor/budoux-ja.js … 日本語の改行位置を整えるライブラリ（Google製・無料。編集不要）
│   └── main.js           … config.js の内容をページに反映する処理（通常は編集不要）
└── assets/images/
    ├── placeholder-profile.svg … 顔写真が未設定のときの仮画像
    ├── favicon.svg / favicon-32.png / apple-touch-icon.png … ブラウザのタブ等に出るアイコン
    └── ogp.png           … URLをSNSやLINEで共有したときに出る画像（1200×630）
```

**サンプルと本番データの分け方**
- 本番データ … `config.js` と、あとから置く `assets/images/profile.jpg`
- サンプル・仮素材 … `config.example.js`、`placeholder-profile.svg`

## 2. 内容の差し替え方法

すべて `config.js` をテキストエディタ（VS Code、メモ帳など）で開いて編集します。
`""`（ダブルクォーテーション）の**間**に入力してください。

### 氏名
```js
name: "山田 太郎",
nameEn: "Taro Yamada",   // ローマ字（不要なら "" のまま）
```
→ ヘッダー・ファーストビュー・自己紹介・フッターにまとめて反映されます。

> ⚠️ 検索結果やSNS共有時のタイトルは `config.js` では変わりません。
> `index.html` の `<title>` と `og:title` の先頭に氏名を書き足してください（例：`山田 太郎 | 動画編集（YouTube・ショート動画）`）。

### 顔写真
1. 写真を **正方形・600×600px程度・JPG形式・200KB以下** に整える（表示速度のため）
   - Macなら「プレビュー」アプリ →「ツール」→「サイズを調整」で縮小できます
2. `assets/images/profile.jpg` という名前で保存
3. `config.js` を編集
```js
photo: "assets/images/profile.jpg",
```
空欄のままだとグレーの仮画像が表示されます。

### メールアドレス
```js
email: "your-address@example.jp",   // 実際のアドレスに
mailSubject: "【お問い合わせ】動画編集について",
```
- 空欄のあいだは「メールで問い合わせる」ボタンが**押せない状態**になり、「準備中」と表示されます
- `@example.com` などの例示用アドレスを入れた場合も、誤送信防止のため無効のままになります

### 動画制作実績（YouTube）
```js
works: [
  {
    url: "https://www.youtube.com/watch?v=動画ID",
    format: "normal",          // "normal"＝横型（通常）／"short"＝縦型（ショート）
    title: "動画のタイトル",
    type: "ビジネス系YouTube動画",
    tasks: ["カット編集", "テロップ", "演出", "BGM・効果音"],
  },
  ...
]
```
- `url` は `youtube.com/watch?v=…`、`youtu.be/…`、`youtube.com/shorts/…` のどれでもOK
- `format` で表示形式を選べます。**2本とも、それぞれ自由に選べます**（例：2本とも通常、1本だけショート、2本ともショート）
  - `"normal"` … 横長（16:9）で表示
  - `"short"` … 縦長（9:16）で表示
  - 書かなかった場合は、URLに `/shorts/` が含まれていればショート、それ以外は通常として表示します
- `type` は表示用のラベルです（「ビジネス系ショート動画」「Instagramリール動画」など自由に変更可）
- サムネイルはYouTubeから自動で表示されます。タップするとページ内で再生されます
- 最初はサムネイル画像だけを読み込み、タップされたときに動画を読み込むので、ページ表示が重くなりません
- `url` が空欄のカードは「動画準備中」と表示されます
- `tasks`（担当した編集内容）は、**実際に担当した作業だけ**に書き換えてください（初期値は仮です）
- 3本目を足したい場合は `{ ... },` のブロックをコピーして追加すれば自動で増えます

### 料金
金額・文言はすべて `config.js` の `pricing` にまとまっています。
```js
rows: [
  ["10分以内", "15,000円〜"],   // ["左の列", "右の列"]
  ["20分超", "別途お見積もり"],
],
```
- 金額を変えるときは、右側の文字を書き換えるだけです
- 数字で始まる金額（`15,000円〜` など）は、数字が大きく表示されます
- 行の追加・削除もできます（`[...],` の1行を足す／消す）
- 修正回数は `revision`、注意事項は `notes` で変更できます

### AI活用・業務効率化のご案内（紹介サイトへのリンク）
ページ最下部の「AI活用・業務効率化関連はこちら」ボタンの移動先は、`config.js` の `ai` で設定します。
```js
ai: {
  url: "https://（AI活用の紹介サイトのURL）",
},
```
- ボタンを押すと、紹介サイトが新しいタブで開きます
- 空欄のあいだはボタンが押せない状態になり、「紹介サイトは現在準備中です。」と表示されます
- `https://` または `http://` で始まるURLを入れてください（それ以外はボタンが有効になりません）

### 文章・色・フォント
- 文章（自己紹介文・サービス内容など）は `index.html` を直接編集します
- 色は `css/style.css` の先頭 `:root { ... }` の値を変えるとサイト全体に反映されます
- デザインは黒×グレーのモノトーンです。英字は Marcellus、日本語は Noto Serif JP（明朝体）を使っています（どちらもGoogle Fontsの無料フォント）
- 日本語の改行は、単語や意味のまとまりの途中で切れないよう自動で調整しています（BudouX を使用）。文章を書き換えても、そのまま正しく改行されます
- 文章の中で「ここで必ず改行したい」場所には `<br>`、「改行してもよい」場所には `<wbr>` を入れてください
- ファーストビューの大きな英字「VIDEO EDITING」は装飾です。`index.html` の `hero-display` の部分で変更できます

## 3. 手元で表示を確認する方法

**簡単な方法：** `index.html` をダブルクリックしてブラウザで開く
（ただし、この方法だとYouTubeの再生がブロックされる場合があります）

**確実な方法：** ターミナルで以下を実行し、ブラウザで http://localhost:8000 を開く

```bash
cd ~/Desktop/Obsidian/Profile/portfolio-site && python3 -m http.server 8000
```

終了するときはターミナルで `Control + C` を押します。

## 4. 公開方法（すべて無料で可能）

### おすすめ：Netlify（いちばん簡単）
1. https://app.netlify.com/drop を開く（無料アカウント作成が必要）
2. `portfolio-site` フォルダーを画面にドラッグ＆ドロップ
3. 数十秒で `https://〇〇〇.netlify.app` のURLが発行されます
4. 「Site configuration」→「Change site name」で、URLの〇〇〇部分を好きな名前に変更可能
5. 内容を更新したときは、「Deploys」画面に同じフォルダーを再度ドロップ

### その他の選択肢
- **Cloudflare Pages** … Netlifyと同様にフォルダーのアップロードで公開できます
- **GitHub Pages** … GitHubアカウントが必要。更新履歴を残したい場合に向いています

### 公開URLが決まったら必ずやること
`index.html` の以下3か所の `https://example.com/` を、実際の公開URLに書き換えて再アップロードしてください。
```html
<link rel="canonical" href="https://example.com/">
<meta property="og:url" content="https://example.com/">
<meta property="og:image" content="https://example.com/assets/images/ogp.png">
```
これをしないと、LINEやSNSでURLを送ったときに画像付きで表示されません。

- [ ] 実績動画2本のURL・タイトルを入力した

- [ ] 実績動画の「担当した編集内容（tasks）」を実際の担当作業に修正した

### 確認事項（リスクがある項目）
- [ ] **実績動画の掲載許可**：クライアントの動画を載せる場合、ポートフォリオ掲載の許可を得ているか（契約で禁止されていることもあります）

- [ ] **メールアドレス**：サイトに載せたアドレスは迷惑メールが届きやすくなります。副業専用のアドレス（Gmailで新規作成など）の利用がおすすめです
- [ ] **顔写真**：顔出しして問題ないか（イラストやロゴ画像に差し替えても構いません）

### 表示確認
- [ ] スマートフォン（実機）で表示を確認した
- [ ] 各メニューを押して、該当箇所にスクロールすることを確認した
- [ ] 動画のサムネイルをタップして再生されることを確認した

## 6. 技術メモ
- 同梱ライブラリ：BudouX 0.9.3（Google製、Apache-2.0ライセンス。商用利用可）。日本語用の部品だけを `js/vendor/budoux-ja.js` に収めています
- 外部サービスは「Google Fonts（Marcellus／Noto Serif JP）」と「YouTube（サムネイル・動画再生）」のみ。どちらも無料・登録不要
- YouTubeはプライバシー強化モード（youtube-nocookie.com）で埋め込んでいます
- 動きは「背景のゆっくりした揺らぎ」と「スクロール時のフェードイン」だけです。端末で「視差効果を減らす」設定の方には、これらとスクロールのアニメーションも止まります
- メニューは画面下に常に表示され、親指で押しやすい位置にあります。いま見ているセクションには下線が付きます
- キーボード操作・読み上げソフトにも配慮しています（スキップリンク、現在地の読み上げなど）
- デザインは参考サイト（details.co.jp）の雰囲気を参考にしたもので、ロゴ・写真・文章などの素材は使用していません
